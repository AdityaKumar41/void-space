Navigate and select

Drag with the middle mouse button to orbit; Shift + middle drag pans. Scroll to zoom. The axis buttons choose a view, and Frame Selected centers the selected object. Click an object to select it; click empty space to deselect. Use A to toggle all and Alt+A to deselect.

Build and edit meshes

Use Add or Shift+A to create a primitive. Tab switches a compatible selected mesh between Object and Edit Mode. The mode chooser also offers Sculpt Mode for SculptCore geometry. LeafMesh supports Object and Edit Mode. Edit Mode provides vertex, edge and face selection and a Mesh menu with the tools supported by the selected geometry backend.

G moves, R rotates and S scales. While transforming, X/Y/Z constrains an axis and a number sets the amount; Enter confirms and Escape cancels. The left toolbar activates the corresponding transform gizmo. X or Delete deletes selected elements in Edit Mode and selected objects in Object Mode.

Sculpt and inspect

Choose Sculpt Mode on SculptCore geometry, then choose a brush and its settings in Active Tool. The Properties icon rail provides Object transforms, Object Data, Material, Texture, Scene, World and Render settings. Hover icons for their names. The Outliner selects objects and provides visibility, selection-lock and delete controls. Double-click an object name to rename it.

Save, import and export

File → Save As downloads a native project; File → Open loads one. File → Load Last Autosave restores a browser-local recovery copy when available. Use File → Import 3D Asset for supported formats. Export GLB, OBJ, STL or PLY through File. Native projects preserve editor data; interchange formats preserve supported geometry and attributes. STL does not store UV coordinates.

Undo and workspace controls

Ctrl+Z (Command+Z on macOS) undoes, and Ctrl+Shift+Z (Command+Shift+Z) redoes. H hides selected objects and Alt+H reveals objects. T toggles the left toolbar; N toggles the viewport sidebar. Z cycles display shading. Workspace tabs change the editor layout.

Browser-only availability

Studio runs locally in your browser using WebGPU. Use a browser and graphics device that support WebGPU. GitHub Pages supplies the editor; cloud AI, collaboration and other server-dependent integrations require a configured service and are unavailable when no backend is connected. This editor implements a modeling subset and does not provide complete Blender parity.
